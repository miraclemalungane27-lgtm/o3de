# FORBIDDEN ENGINE (FE)

## Platform
- **Native Windows PC EXE only**
- Forbidden Engine only runs on Windows PC

---

## Development Phases

### Phase 1: Enhanced O3DE Fork
- Fork O3DE with enhanced nodes, workspace, and editor improvements

### Phase 2: Godot 4 Integration
- Integrate with Godot 4 marketplace
- Enhance FE marketplace with IPA, EXE, and AAB builder capabilities

### Phase 3-4: Physics System
- Fork O3DE physics engine
- Integrate: Jolt + COACD + Splash Splash + MeshOptimiser

### Phase 5: Animation System
- Fork O3DE animator
- Integrate: OZZ Animation + Fabrik/OpenIK + Motion Matching + Wiggle Bones

### Phase 6: Advanced Rendering
- PBRT + MeshOptimiser
- Basis Universal + KTX Software
- XAtlas + AMD FidelityFX
- Recast + Detour
- MaterialXI + OpenPBR
- Tracy Profiler + Slang

### Phase 7: Advanced Graphics & Rendering
- Google Filament
- Intel Open Image Denoise
- Volk (Vulkan Meta-Loader)
- Microsoft DirectXTex
- OpenColorIO (OCIO)
- FSR 3.0
- LuxCoreRender
- MoonRay

### Phase 8: Scripting System
- Default: C++
- Supported Languages: C#, Lua
- Error detection system built-in

### Phase 9: Full Visual Editor & Game Engine
- Complete visual editor and script editor
- Full node system, meshes, and scene tree
- Gizmo system
- Complete game engine editor

#### Project Management
- Auto-create home folder storage for projects on installation
- Each project gets its own folder inside FORBIDDEN ENGINE directory
- 7-step deletion process (must delete within FE, not externally)
- 1-second auto-save feature

#### Build System
- Built-in EXE, IPA, and AAB creator libraries
- Convert project folders into installable builds
- 5-step update process
- Players can update without losing data
- Asset plugins system (FE Asset Store)

#### Editor Features
- Black UI with white accents (no comments on UI)
- Full gizmo system
- Node-based workspace with dedicated layout per project
- Responsive buttons and controls
- Error detection integrated into editor

#### Scripting & Customization
- Default language: C++
- Pre-written node components (modifiable)
- Ability to add custom physics and animation on top of default libraries
- Multi-language support (mix C++, C#, Lua)
- Override or erase pre-written components as needed
- Scene starts with: Daylight, Gizmos, White Box at fixed position (rotatable)

#### Version Control
- Version Rollback/Rollup in 7 steps
- Immediate player updates upon version change
- Differential updates (players don't download entire app)
- Smart delta detection between builds

#### Branding
- FE Logo on splash screen
- Games display "Made with FE" branding
- Logo visible on all exported builds

### Phase 10: Logo Design

#### Logo Concepts

**1. Cybernetic Tech Monogram**
- Sharp, high-contrast interlocking monogram
- Letters F and E merge into single cohesive symbol
- Unified layout matching editor tools

**2. Angular Geometric Cut**
- Clean, sharp-edged segments
- F and E silhouette inside shield or custom polygon
- Professional, technical appearance

**3. Abstract Circuit/Lines**
- High-tech vector line work
- Parallel glowing lines trace initials
- Matches node-based editor theme

**4. Symmetrical 3D & Virtual Geometry Glyphs**

**5. 3D Isometric Block**
- Abstract interlocking architectural structure
- Sharp angles
- Mirrors advanced voxel geometry and rendering pipelines

**6. Industrial Shield**
- Hard-edged, aggressive, symmetrical crest
- Professional, heavy-duty software environment aesthetic

#### Logo Requirements
- **Color**: White accents and white background
- **Style**: NOT plain text
- **Consistency**: Use everywhere across engine and branding
- **Integration**: Display on splash screen, editor UI, and all exports
